# mondrAIn

Desktop WPF app for exploring one image through reversible transformations (grayscale, ASCII, color shifts, flip/mirror). Upload an image, view it as an in-memory pixel grid, and try effects on the original - no destructive edit stack.

**Build:** `dotnet build mondrAIn.slnx`  
**Run:** `dotnet run --project src/MondrAIn.App/MondrAIn.App.csproj`
